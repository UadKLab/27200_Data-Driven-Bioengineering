# 27200 Data-driven Bioengineering

This repository contains the hands-on course material for **27200 Data-driven Bioengineering** at DTU Bioengineering, Autumn 2026.

The course develops a common foundation for reasoning across biological systems, data, models, and AI-enabled workflows. It is intentionally broad: the aim is to recognise transferable patterns across technologies, datasets, and biological questions—not to become a technical specialist in every method in one semester.

## Where to find course information

- **DTU Learn** is the authoritative source for announcements, practical information, preparation tasks, and course communications.
- **This repository** contains notebooks, exercises, code, selected data, and week-specific supplementary material.
- Material will normally be released with the relevant preparation information approximately one week before the session. Slides are released shortly before the associated lecture.

## Working with the material

Each weekly folder will use the following convention as material is released:

```text
prep/         Preparation tasks and reading
notebooks/    Jupyter / Colab notebooks
exercises/    Instructions, starter files, and active-learning tasks
data/         Small teaching datasets or download instructions
solutions/    Instructor-released solutions, where appropriate
```

Use the week README first. It states the preparation, learning aims, practical environment, and any session-specific instructions.

## Learning approach

Sessions combine short teaching segments with individual reasoning, group work, discussion, and hands-on computational exercises. You will work with bioinformatic tools, terminals, notebooks, HPC, Colab, Codespaces, and related environments. Python is the main working language, but the emphasis is on biological and computational reasoning rather than loyalty to a particular language.

AI systems and coding agents can be useful helpers, tutors, and collaborators. They are not oracles. You remain responsible for the question you ask, the code and outputs you use, the validation you perform, and the conclusions you submit.

## Assessment and feedback

- Mid-term integrative assessment: **30%**
- Final group project and presentation: **70%**

Groups will be assigned by the course team to balance relevant competencies. Quizzes, peer feedback, insights and muddy points, and rotating feedback persons support formative learning throughout the course.

## Repository expectations

- Do not upload personal data, confidential data, or credentials.
- Do not commit large raw datasets unless explicitly requested; use documented download steps or teaching-sized subsets.
- Keep notebooks reproducible: state required packages, random seeds where relevant, and the expected order of execution.
- Cite external datasets, figures, code, and model outputs in the relevant week folder.
