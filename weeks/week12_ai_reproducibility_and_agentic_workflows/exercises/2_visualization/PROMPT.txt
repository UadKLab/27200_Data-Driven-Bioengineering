Looking at the map, the spectra seem to cluster by organism. I do not believe it.

Each organism was probably measured in a single project, on one instrument, with one
method. So "clusters by organism" and "clusters by project" look the same in the picture,
and enrichment numbers cannot tell them apart.

Give me a test that can. The question is: does a label L still predict which spectra are
neighbours once a covariate C is held fixed?

  - Build a k-nearest-neighbour graph (k = 15) on umap_x and umap_y.
  - For a pair (L, C): among neighbour pairs that share the same C, how often do they also
    share the same L?
  - Compare that with a null in which L is shuffled within each C group.
  - Only use C groups that contain at least two L categories. Report how many groups
    qualify and what share of neighbour pairs they cover. If very few qualify, say that the
    test is weak.
  - Also report the reverse: how often neighbours share C when they share L.
  - Run a permutation test (shuffle L within C groups, 100 times) and give a z-score.

Run it for organism within project, instrument within project, and fragmentation within
project. Tell me in plain words which apparent clusters survive and which are covariates.
If L is completely determined by C, say the comparison is impossible instead of giving a
number.

Save the results as covariates.md and the code as covariates.py.
