# Sources

The `.md` files in this folder are the open-access full texts, converted from the journals'
XML so that AI tools can read them with fewer tokens and without PDF errors. Figures are not
included, but their captions are. **Cite the original papers, not these files.**

A paper's short name - the part of the file name before the first `_` - is how cards cite
it, for example `(Hofner2025, Results)`.

## Hofner2025

Höfner M, Schneider M, Jiang Y, Schneider J, Herrmann C, Mayr D, Forné I, Mayerhofer A.
The impact of hypoxia on the cellular phenotype and proteome of KGN cells.
*Reproduction and Fertility* 6(4): e250017, 2025. doi:10.1530/raf-25-0017

The proteomics data in exercise 1 comes from this study (PRIDE PXD056016).
