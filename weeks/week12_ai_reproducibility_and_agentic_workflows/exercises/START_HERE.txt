3. START AN EXERCISE

  Codex app, or the Claude app (Code tab): open the exercise folder as your project
  (choose a folder when you start).

  In a terminal: go into the exercise folder, and start your agent there:
      cd path/to/exercises/3_knowledge_cards
      copilot      (or: agy)

  Starting it inside the folder matters: the agent can read and write the files in that
  folder, and only those. If it asks whether to trust the folder, say yes.

  Then give it the prompt. Either type:
      Read PROMPT.txt and follow it.
  or copy all of PROMPT.txt and paste it in. Each exercise's README.txt tells you what to
  do next and what to check.


GIVING THE AGENT FILES

  The agent already sees every file in the folder you started it in. To point it at one
  file in your message, type @ followed by the file name:

  Codex app         Type @ and pick the file, or drag the file into the message box.
  Copilot CLI       Type @ and the path, e.g.  Explain @README.txt
                    You can also drag a file from your file browser into the terminal.
  Antigravity CLI   Type @ and the path, e.g.  Summarise @sources/SOURCES.md
                    If your version does not complete it, just write the file name.
  Claude app        In the Code tab, type @ and pick the file, e.g.  @PROMPT.txt

  Do NOT @-attach the data files (proteinGroups.txt, umap_spectra_25k.csv). They are far
  bigger than the context window. Name them, and let the agent read them with code - that
  is exactly the habit from the lecture.


APPROVALS
  The agent asks before it runs a command or changes a file. Read what it wants to do, then
  approve. Do not switch on "approve everything" modes on your own computer.


YOUR LIMITS
  The free tiers are small. Read what the agent prints before you ask again, and keep
  prompts specific. If you hit a limit, wait, or continue another day from your notes
  (below). Type / in your agent to see its commands, including how to check your usage.


KEEP NOTES
  Every prompt asks the agent to keep a NOTES.md as it works. If a session stops, start a
  new one in the same folder and type:
      Read NOTES.md and continue from the next step.


IF SOMETHING DOES NOT WORK
  - "command not found" after installing: close the terminal and open a new one.
  - npm not found: install Node.js first (link above).
  - Ask us. We would rather help you in the first ten minutes than find you stuck at the end.


ABOUT THE DATA
  Everything here is public (each README says where it comes from). That is why a free tier
  is fine today. Do not use free tiers like this for confidential or unpublished data.
