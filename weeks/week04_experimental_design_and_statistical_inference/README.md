## Exercise — t-tests and p-values

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/UadKLab/27200_Data-Driven-Bioengineering/blob/main/weeks/week04_experimental_design_and_statistical_inference/notebooks/T_test_R.ipynb)

**`notebooks/T_test_R.ipynb`** — simulate two groups of measurements, look at them, and then run a
t-test on them. The point is to connect what a p-value says with what the data looks like: you set
the means, the spread and the number of points yourself, so you can watch which of those the test
actually responds to. Two questions at the end ask you to change the parameters and explain what
happened — whether you changed the signal or the noise.

> **This notebook is written in R, not Python.** Colab starts an R runtime for it automatically —
> you do not need to change anything. The first cell installs the `beeswarm` plotting package, which
> takes a minute; let it finish before running the rest.
